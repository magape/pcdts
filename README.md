# Palatul Copiilor Drobeta-Turnu Severin

Acest repository centralizează informații publice despre Palatul Copiilor Drobeta-Turnu Severin.

## Despre instituție

Palatul Copiilor Drobeta-Turnu Severin este o instituție de educație non-formală dedicată copiilor și tinerilor, cu activități care completează pregătirea școlară prin cercuri și proiecte educative, artistice, tehnice și sportive.

## Activități și cercuri

Instituția pune la dispoziția copiilor și tinerilor cercuri și activități din mai multe domenii, printre care:

- activități artistice;
- activități tehnico-științifice;
- activități sportive;
- ateliere și proiecte de dezvoltare personală.

## Informații utile

- participarea la activități este destinată copiilor și tinerilor;
- înscrierea se face pe baza unei cereri depuse de părinte sau tutore;
- programul cercurilor și anunțurile curente pot fi consultate pe website-ul instituției.
